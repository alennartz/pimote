Session identity surface

Four ways to hand over the pi session ID and the session file path.

Mock of proposed Pimote UI · values from a live session
  • The path is long: ~/.pi/agent/sessions/--home-alenna-repos-Ide-hub--/…jsonl
  • The details sheet has no room for it on a phone, and desktop has no details sheet at all.
  • A context-menu item copies the value with one tap and no layout cost.
  • The info dialog wins when you need to read the value before copying it.
